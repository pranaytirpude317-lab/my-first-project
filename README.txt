IRONFORGE - Pure HTML, CSS & JavaScript

This version has been converted to run without React, TypeScript, Vite, npm, pnpm, or any build tool.

Files:
- index.html   -> website structure/content
- styles.css   -> design/responsive layout/animations
- script.js    -> menu, form handling, counters, scroll effects
- images/      -> existing project images

How to run:
1. Extract this folder.
2. Open index.html directly in a browser.

The contact form is client-side only; it does not send data to a server.
